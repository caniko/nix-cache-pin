nix-cache-pin

Pin nixpkgs to revisions where your packages are cached

A flake-parts module that queries Hydra and narinfo, then rewrites your nixpkgs input pin to the newest revision where every required package already has a binary cache hit.

View sourceQuick start

Proven cache hits

A revision is accepted only after narinfo confirms the package is substitutable, and malformed or incomplete cache metadata is rejected before acceptance.

Hydra first, commits second

Recent nixpkgs evaluations are queried on Hydra, and the search falls back to scanning GitHub commits when a package has not been built there yet.

Consumer-aware targets

Required outputs are evaluated from your consuming flake with nix eval --override-input, so follows, overlays and host-specific package selection are included.

Fail-before-write updates

flake.nix, flake.lock and the cache-pin.lock.json manifest change in one guarded transaction, and a blocked plan exits non-zero without editing any file.

Declare the input

Import the module, then list the packages and the flake input that must supply them from a binary cache.

{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixpkgs-unstable";
    flake-parts.url = "github:hercules-ci/flake-parts";
    nix-cache-pin.url = "github:caniko/nix-cache-pin";
    nixpkgs-rocm.url = "github:NixOS/nixpkgs/<some-rev>";
  };

  outputs = inputs:
    inputs.flake-parts.lib.mkFlake {inherit inputs;} {
      imports = [inputs.nix-cache-pin.flakeModules.default];
      systems = ["x86_64-linux"];

      cache-pin = {
        nixpkgs = inputs.nixpkgs.legacyPackages.x86_64-linux;

        pins.rocm = {
          packages = ["torchWithRocm" "torchvision"];
          wishPackages = ["obs-studio-plugins.obs-backgroundremoval"];
          inputName = "nixpkgs-rocm";
          attrPrefix = "pkgsRocm";
          pythonPackages = "python313Packages";
        };
      };
    };
}

Quick start

Add nix-cache-pin as a flake input, import the module and declare the packages you need cached. The generated app then searches for the newest fully cached revision of each pinned input.
